# Blog Post Ordering — Editor Guide

Oct 22, 2026 · @Tinyflow

## How the blog is ordered

Posts are listed newest first by whichever is later: the **Published Date** or the **Updated Date**. A post you rewrite and mark as updated today moves to the top, even if it was first published two years ago.

The original **Published Date** never changes and is still shown on the post. Posts with an Updated Date also show an "Updated:" line.

The newest post appears as the large featured card. The grid below starts from the second newest, so no post appears twice.

## The three date fields

You only ever fill in the first two. Sort Date takes care of itself.

| Field | Required | What you do | What it controls |
| --- | --- | --- | --- |
| Published Date | Yes | Set once, when the post first goes live. Never change it after a rewrite. | The "Published:" date on the post |
| Updated Date | No | Set it only when the post is substantially rewritten. Leave it empty otherwise. | The "Updated:" line, and moves the post up the list |
| Sort Date | Automatic | Nothing. Do not edit it. | The order of the blog list |

Sort Date is filled in automatically within about a second of saving. If someone edits it by hand, it is corrected on the next save.

## Common tasks

**Publish a new post**

1. Set the Published Date. Leave Updated Date empty.
2. Save, then publish.

**Mark a rewritten post as updated**

1. Open the post and set the Updated Date to today.
2. Do not touch the Published Date.
3. Save, then publish. The post moves to the top of the blog.

**Undo an update**

1. Clear the Updated Date.
2. Save, then publish. The post returns to its place by Published Date.

Small fixes (a typo, an image, alt text) do not need an Updated Date. Leave it as it is and the post keeps its position.

## Good to know

- **Sort Date may look out of date while a post is open.** The Editor shows the value from when you opened the post. Close and reopen it to see the new one. The live order is correct either way.
- **Drafts don't change the live blog.** Saving a date on an unpublished change moves nothing on the live site until you publish.
- **Time of day counts for updates.** The Published Date has no time, so it counts as the start of that day. An update made later the same day therefore ranks above a post published that day.
- **Two posts with the exact same date** are ordered alphabetically by name.

## If something looks wrong

| You see | Try this |
| --- | --- |
| A post is in the wrong place on the live blog | Check that the post is published, not just saved. |
| Sort Date didn't change after you saved | Close and reopen the post. It updates within a second. |
| Still wrong after publishing | Contact Tinyflow with the post name. We can recheck every post in one step. |

Don't fix the order by editing Sort Date by hand. The automation overwrites it on the next save.
